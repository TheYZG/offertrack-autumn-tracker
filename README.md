# OfferTrack 秋招进度管理

OfferTrack 是一个轻量的个人秋招企业清单，将上级目录 `秋招.md` 中的 45 家企业、招聘入口和已有阶段结构化后展示，并通过 D1 数据库存储后续新增和修改。

## 当前能力

- 只记录企业名、当前阶段、投递时间和企业网站地址
- 企业搜索与阶段筛选
- “流程中”自动排除已结束的企业
- “待更新”每天自动恢复为全部流程中企业，点击企业官网后移出当天列表
- 按投递时间从早到晚排列，同日的初始企业保持原 Markdown 顺序
- 每页显示 10 家企业并支持翻页
- 点击企业名直接改名，点击当前阶段直接切换状态
- 点击企业行空白处打开官网，列表末尾可一键标记为已结束
- 新增时提醒同名企业或重复网址
- 阶段精简为简历筛选、测评、笔试、面试、Offer 和已结束
- 新增企业记录并在列表中完成日常更新
- 一键打开企业招聘网站
- 数据持久化保存
- 支持独立账号密码注册与登录，可选择保持登录 30 天
- 按站内账号隔离数据，每个用户只能读取和修改自己的企业记录

首个注册账号会接管现有 45 条初始数据。其他用户注册后从空列表开始，之后的新增与修改只保存在自己的账号空间中。密码使用 PBKDF2 加盐哈希保存，保持登录依赖安全的 HttpOnly 会话 Cookie，不在网页中明文保存密码。

## 本地运行

建议使用 Node.js 22.x；当前 Vinext 在 Windows Node.js 24 下可能在构建结束时触发底层退出断言。

```bash
npm install
npm run dev
```

默认地址为 `http://localhost:3000`。

## 检查

```bash
npm run lint
npm run build
```

数据库结构位于 `db/schema.ts`，迁移文件位于 `drizzle/`。修改结构后执行 `npm run db:generate`。
